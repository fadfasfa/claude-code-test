# claudecode

`claudecode` 是多工作区本地开发仓库。Claude Code 与 Codex 均可独立工作；仓库只保留轻量规则、工作区边界和高危操作约束。

## Daily Entry

- 人类快速入口：本文件。
- Agent 仓库地图：`PROJECT.md`。
- Codex 常驻边界：`AGENTS.md`。
- Claude Code 入口：`CLAUDE.md`。
- 文档发现索引：`docs/index.md`。

工作区清单、workflow 规则、Git/PR 约定、脚本边界和历史归档都从 `docs/index.md` 继续发现；README 不维护第二套 agent 规则。

本仓治理说明、计划和任务总结默认使用简体中文；技术标识符、路径、命令和错误原文保持原文。
