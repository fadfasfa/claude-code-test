# 版本驱动检测与更新

当前为官方名单与release v4源码合同；未部署，不代表真实网络/游戏验收通过。

## 周期不是有效期

ARAMKit、Apex、Mayhem正常检测间隔4小时，Catalog正常检测24小时。只在程序运行时检查，不新增系统后台服务。到期是检测机会，不是数据失效，也不表示全量下载；手动刷新沿用单次检测/合并语义。

官方海克斯名单来自腾讯`kiwi_augments.json`，精确KIWI模式、非PBE；`isNew`不影响身份准入。官方名字、内部名、等级与ID同一修订绑定，CDragon仅补充资源。ARAMGG和Blitz不参与当前生产调度。

## 请求与恢复

- 官方与其他支持来源使用既有ConditionalResponseCache。304只能复用校验通过的正文；缺失/损坏最多补一次无条件GET。错误响应不冒充成功。
- ARAMKit固定dataPath原文按source/revision/URL缓存；新revision不复用旧原文。重复失败按版本、处理revision和Catalog绑定去重。
- 未知身份只合并触发一次官方名单复检，允许越过正常检查间隔，不越过网络退避或Retry-After。
- 成功采用不同Catalog后，仅绑定旧Catalog的validation等待可解除，优先从缓存重投影；未变化Catalog或网络故障不触发无限重试。
- 每来源保存真实检查时间与状态；not_due不更新成功检查时间。可选资源失败不声称资源已最新，缺图不删除官方身份。
- 正常网络故障沿用有界退避与服务端Retry-After；schema/身份校验失败单列。失败不清空已验证数据，也不把未知ID猜成其他身份。

## 发布与使用

历史 manifest 不改写；坏immutable unit不覆盖，而是生成独立修复单元。不同英雄unit不能借ranking状态冒充最新。

不可变ranking、每英雄all/Stage1–4与联动各存一份，v4 release只引用精确单元。相同业务内容不创建generation、不移动previous；观察时钟不进入业务内容hash。

识别目录独立发布，统计只在首选截止前采用当前英雄已完整版本；截止后本局冻结。识别词表变化需安全换代，不降低0.95 exact与3/5门。正式名录中未列出不等于实时热禁用。

## 验收

覆盖200/304/坏缓存、网络退避、相同内容、版本漂移、未知身份合并复检、Catalog恢复后缓存重投影、局中冻结与重启。分别核对请求、下载、unit、release写入量与实际采用结果，不用状态文案代替数据验证。隔离回放与单元测试不替代真实五局、原生窗口或最终呈现验收。
