# 目录职责

本文件说明仓库目录职责和生命周期。根目录只保留入口、治理文件、工具骨架和独立工作区。

## 生命周期类型

| 类型 | 含义 | 示例 |
| :--- | :--- | :--- |
| active-source | 当前源码或规则事实源 | `docs/当前规则/`, `run/hextech/` |
| active-tooling | 当前仓库辅助入口 | `scripts/`, `.agents/skills/`, `.claude/commands/` |
| reference | 按需读取背景资料 | `docs/参考资料/` |
| archive | 历史归档，不作为当前入口 | `docs/历史归档/` |
| local-state | 本机状态，默认不提交 | `.state/cc-work/` |
| ignored-artifact | 构建/发布产物，默认不提交 | `.artifacts/`, `run/dist/` |
| local-private | 本地私有工作区 | `QuantProject/` |
| external-gitlink | 外部 Git 项目入口 | `qm-run-demo` |

## 当前布局

| 路径 | 职责 |
| :--- | :--- |
| `AGENTS.md` / `CLAUDE.md` / `PROJECT.md` / `README.md` | 仓库入口 |
| `docs/index.md` | 唯一文档发现索引 |
| `docs/当前规则/` | 当前 workflow 规则事实源 |
| `docs/参考资料/` | 按需读取的参考资料 |
| `docs/历史归档/` | 历史报告和退役资料，默认不读 |
| `docs/方案草稿/` | 设计草稿，不作为默认事实源 |
| `docs/方法论规格/` | 方法论规格、计划等非活动文档 |
| `.agents/skills/` | 仓库级 Codex skill 白名单；不放旧 bridge 执行入口 |
| `.claude/` | Claude Code 本机设置、commands、skills、plans、worktrees |
| `.codex/` | 项目级 Codex 配置占位，不放运行态 |
| `.state/workflow/` | 旧 CC-CX 工作流遗留运行态，默认不提交 |
| `.state/cc-work/` | 本机 agent 计划、协作、交接、审查草稿区 |
| `scripts/` | 仓库级辅助脚本；旧 `scripts/workflow/` 已移除 |
| `scripts/Git辅助/` | legacy/manual Git 辅助脚本 |
| `scripts/抓取快照/` | 低频手动抓取快照脚本 |
| `scripts/自检测试/` | 仓库级自检测试 |
| `run/` | Hextech 业务运行区；本轮治理重构不触碰 |
| `sm2-randomizer/` | Space Marine 2 随机器工作区 |
| `sms-monitor/` | 接码监控工作区 |
| `heybox/` | 黑盒抓取工作区 |
| `subtitle_extractor/` | 字幕工具工作区 |
| `QuantProject/` | local-private，本地私有工作区 |
| `qm-run-demo` | external-gitlink，发布示例仓；当前只保留 gitlink，不在本轮维护 `.gitmodules` |

## Runtime State

`.state/workflow/**` 是旧 CC-CX 工作流遗留运行态目录；当前工作流不依赖旧任务结果文件。`.state/cc-work/**` 用于本机计划、协作草稿、交接稿和审查草稿，不是正式文档区。`.claude/plans/**` 只用于 Claude Code 原生运行时本机计划草稿，默认不提交。
