# superpowers-project-bridge 归档说明

本文件记录 `claudecode` 旧的仓库级 Superpowers 桥接说明，已退役。

## 退役状态

- 不再作为 `.agents/skills` 下的可扫描 skill。
- 不再作为 `S/M/L` 的执行入口、加载入口或 wrapper 入口。
- 现行 Superpowers 来源以官方已安装 plugin 为准；仓库只保留薄的 S/M/L 治理边界。

## 历史职责

- 旧职责是把仓库内的风险路由、验证和收尾流程绑定到单一桥接层。
- 该职责已被拆分为仓库入口说明、workflow 短规则和官方 plugin 来源三层。
