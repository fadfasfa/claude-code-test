# 治理结构重构执行计划

> 给后续执行 agent 的硬要求：执行本计划前必须使用 `superpowers:subagent-driven-development` 或等价的阶段式子智能体审查流程。每个阶段使用 checklist 记录进度；阶段审查未通过，不得进入下一阶段。

## 目标

把 `claudecode` 的非业务治理层重构为中文可浏览、职责清晰、事实源少而稳定、Skill 不重复维护、PR 修复发布行为明确的结构。

## 本轮范围

只允许修改治理和工具入口：

- `docs/**`
- `scripts/**`
- `.agents/skills/**`
- `.claude/**`
- 根入口文档：`AGENTS.md`、`CLAUDE.md`、`PROJECT.md`、`README.md`
- 路径迁移确实需要时才改 `.gitignore`、`.agyignore`

## 绝对禁止范围

本计划严格禁止改动任何业务工作区，防止和另一个 `run` 重构工作树产生合并冲突：

- `run/**`
- `sm2-randomizer/**`
- `sms-monitor/**`
- `heybox/**`
- `subtitle_extractor/**`
- `QuantProject/**`
- `qm-run-demo`

同时禁止读取或修改凭据类文件：`.env`、`auth.json`、`local.yaml`、`proxies.json`、`accounts.json`、token、cookie、API key、proxy secret。

每个阶段都必须运行业务工作区防冲突检查：

```powershell
git status --short -- run sm2-randomizer sms-monitor heybox subtitle_extractor QuantProject qm-run-demo
git diff --name-only -- run sm2-randomizer sms-monitor heybox subtitle_extractor QuantProject qm-run-demo
```

预期：两条命令都无输出。只要出现任何路径，本阶段立即停止，先移除业务工作区改动。

## 中文硬约束

本计划必须把中文要求写入长期规则，不只依赖本次对话记忆。

- Codex 默认使用简体中文输出计划、进展、问题、风险、验证结果、审查结论和最终总结。
- Claude Code 默认使用简体中文输出计划、进展、问题、风险、验证结果、审查结论和最终总结。
- 子智能体 prompt 必须明确要求“默认中文输出”。
- 后续若生成计划文档、治理文档或任务总结，正文必须使用简体中文。
- 技术标识符、路径、命令、API 名称、错误原文、分支名、Skill 名称保持英文原文。
- 生成英文计划视为未满足本仓维护规则，必须在交付前改为中文。

## PR 修复后自动推送规则

本计划要补强 Codex 发布行为，但不能突破 Git 高危边界：

- 当用户当前轮明确要求 `push`、`推送`、`修复并推送` 或等价发布指令时，Codex 修复 PR 问题后必须完成验证、自审、必要 commit，并自动推送当前 PR 分支。
- 泛化请求如“修复”“完成”“整理”“收尾”“验证”不构成 push 授权。
- push 授权不包含 merge、tag、release、force push、amend、rebase 或历史重写。

## 阶段门禁

每个阶段完成后必须按顺序执行：

1. 主线程运行该阶段验证命令。
2. 派 spec-compliance 子智能体审查是否只完成本阶段目标。
3. 派 maintainability 子智能体审查是否有重复事实源、路径漂移、中文约束遗漏或维护风险。
4. 子智能体发现问题时，先修复并复审。
5. 两轮审查均通过后，才进入下一阶段。

所有子智能体 prompt 都必须包含：

```text
默认使用简体中文输出审查结论、风险和建议；路径、命令和错误原文保持原文。
禁止修改文件，除非当前阶段明确授权你作为 worker 执行写入。
禁止触碰 run/**、sm2-randomizer/**、sms-monitor/**、heybox/**、subtitle_extractor/**、QuantProject/**、qm-run-demo。
```

## 阶段 7：提交和推送门禁

### commit 门禁

只有当前轮明确授权 commit 时才提交。

提交前必须运行：

```powershell
git status --short -- run sm2-randomizer sms-monitor heybox subtitle_extractor QuantProject qm-run-demo
git diff --name-only -- run sm2-randomizer sms-monitor heybox subtitle_extractor QuantProject qm-run-demo
git diff --cached --name-only -- run sm2-randomizer sms-monitor heybox subtitle_extractor QuantProject qm-run-demo
```

预期：三条命令都无输出。

暂存必须使用明确路径，禁止 `git add .`：

```powershell
git add AGENTS.md CLAUDE.md PROJECT.md README.md .gitignore .agyignore
git add docs scripts .agents .claude
git status --short
git commit -m "重构(workflow): 收敛治理目录与 agent 规则"
```

### push 门禁

只有当前轮明确授权 push/推送 时才推送。

```powershell
git push -u origin codex/chore/repo-governance-run-restructure
```

不允许把 commit 授权理解为 push 授权。
