# CC Work 草稿区

这里用于 Claude Code 的计划、协作草稿、交接稿、Codex 最终报告副本和审查草稿。

这里不是正式文档区；普通任务不强制生成文件。

- `.state/cc-work/**` 与 `.claude/plans/**` 是 CC 默认可直接读写的草稿面。
- 业务代码、workflow 正文、Guard 脚本和 protected path 不应写入这里做替代修改。
- 当 CC 需要审查 Codex 结果时，可在这里保留计划、handoff、review note 或结果摘录。

不要把 `.state/workflow/**` 重新作为新主路。
